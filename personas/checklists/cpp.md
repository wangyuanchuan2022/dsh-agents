# C++ 评审清单（code-reviewer v2 伴随资产）

> 总原则：precision over recall。与通用清单合并使用，发现同等定级。覆盖 .cpp/.cc/.h/.hpp。

## 所有权边界

- 适用：仅被评文件扩展名为 .cpp/.cc/.h/.hpp 时加载与套用；其他文件不得引用本清单条款。
- 分工：C++ 特有缺陷归本清单；通用安全/逻辑正确性/代码质量/性能/最佳实践归 code-reviewer 通用清单；发现同等定级，归属冲突按「更具体者拥有」裁决。

## 一、内存安全（裁定依据级）

1. **裸 new/delete**：用 `std::unique_ptr` 或 `std::shared_ptr`。
2. **缓冲区溢出**：C 风格数组、`strcpy`、`sprintf` 无边界。
3. **use-after-free**：悬垂指针、失效迭代器。
4. **未初始化变量**：赋值前读取。
5. **内存泄漏**：缺 RAII、资源未绑定对象生命周期。
6. **空指针解引用**：无 null 检查的指针访问。

## 二、安全（裁定依据级）

7. **命令注入**：`system()` 或 `popen()` 的输入未验证。
8. **格式化字符串攻击**：`printf` 格式串含用户输入。
9. **整数溢出**：不可信输入上的未检查算术。
10. **硬编码密钥**：源码中的 API key、密码。
11. **不安全转换**：无正当理由的 `reinterpret_cast`。

## 三、并发（HIGH）

12. **数据竞态**：共享可变状态无同步。

## 四、评审动作

- 命中即按通用清单定级；每条发现附 file:line + 逐字证据（人格 <Positioning_Integrity> 三级校验）。
- 机器检查（存在则跑、跑不了记 skipped）：clang-tidy / cppcheck。
- 本清单未覆盖的 C++ 模式按通用清单处理；可提议补条目（报告尾部「清单增补建议」）。

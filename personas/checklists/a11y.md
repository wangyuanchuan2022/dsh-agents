# 可访问性（a11y）评审清单（code-reviewer v2 伴随资产）

> 总原则：precision over recall。与语言清单叠加加载（不互斥），发现同等定级。
> 来源：ECC agents/a11y-architect.md:71-107 全量保真提炼（【适配】只加头部映射与行内标注，未删原文语义）。

## 所有权边界

- 适用：.html/.htm 一律加载；.tsx/.jsx 等含 JSX/模板的前端文件与语言清单（ts.md）叠加加载；纯后端文件不套用本清单。
- 分工：WCAG 可访问性缺陷归本清单；通用安全/逻辑正确性归通用清单，语言特有缺陷归语言清单；发现同等定级，归属冲突按「更具体者拥有」裁决。

## 一、WCAG 2.2 AA 四组

### 1. 可感知（Perceivable）

1. **文本替代**：所有非文本内容有文本替代（alt 文本或标签）。
2. **对比度**：文本 ≥4.5:1；UI 组件/图形 ≥3:1。
3. **可适配**：内容在放大到 400% 时 reflow 且保持可用。

### 2. 可操作（Operable）

4. **键盘可达**：每个交互元素可经键盘/开关控制到达。
5. **可导航**：焦点顺序合理，焦点指示器高对比（SC 2.4.11）。
6. **指针手势**：所有拖拽或多点手势存在单指针替代。
7. **目标尺寸**：交互元素 ≥24×24 CSS 像素（SC 2.5.8）。

### 3. 可理解（Understandable）

8. **可预测**：导航与元素标识在整个应用内保持一致。
9. **输入辅助**：表单提供清晰的错误标识与修正建议。
10. **冗余录入**：同一流程内避免重复索要相同信息（SC 3.3.7）。

### 4. 健壮（Robust）

11. **兼容性**：用合法的 Name/Role/Value 最大化辅助技术兼容。
12. **状态消息**：动态变化经 ARIA live region 通知屏幕阅读器。

## 二、五反模式

13. **「点这里」链接**：不可描述——按链接导航的屏幕阅读器用户不知道目的地。
14. **固定尺寸容器**：阻止内容 reflow，高缩放级别下布局破坏。
15. **键盘陷阱**：用户进入组件后无法导航到页面其余部分。
16. **自动播放媒体**：分散认知障碍用户注意力；干扰屏幕阅读器音频。
17. **空按钮**：纯图标按钮无 `aria-label`/`accessibilityLabel`，对屏幕阅读器不可见。

## 三、评审动作

- 命中即按通用清单定级；每条发现附 file:line + 逐字证据（人格 <Positioning_Integrity> 三级校验）。
- 仅前端交付物（.html/.htm/.tsx/.jsx）适用；后端 API 无本清单适用面，相关文件按 skipped 处理而非套用。
- 本清单未覆盖的可访问性模式按通用清单处理；可提议补条目。
